## Примеры отработки программы 

### Ввод команды без параметров (вызов справки)
```
$ node index.js
Справка: Квадратное уравнение имеет вид: ax^2 + bx + c = 0
Укажите свои числовые значения параметров a, b, c.
Пример ввода: node index.js 1 -3 -4
```
### Ввод команды с неверным числом аргументов
```
$ node index.js 1
Ошибка: Введено неверное число аргументов!
Справка: Квадратное уравнение имеет вид: ax^2 + bx + c = 0
Укажите свои числовые значения параметров a, b, c.
Пример ввода: node index.js 1 -3 -4
```
### Ввод команды с неверным типом данных
```
$ node index.js 1 2 qwe
Ошибка: по крайней мере один из аргументов не является числом!
Справка: Квадратное уравнение имеет вид: ax^2 + bx + c = 0
Укажите свои числовые значения параметров a, b, c.
Пример ввода: node index.js 1 -3 -4
```
### Ввод уравнения с a = 0 (не является квадратным)
```
$ node index.js 0 1 2
Ошибка: уравнение не является квадратным.
Справка: Квадратное уравнение имеет вид: ax^2 + bx + c = 0
Укажите свои числовые значения параметров a, b, c.
Пример ввода: node index.js 1 -3 -4
```
### Решени с 2 корнями
```
$ node index.js 1 -3 -4
Решение: x1 = 4, x2 = -1
```
### Решение с одним корнем
```
$ node index.js 16 -8 1
Решение: x = 0.25
```
### Решение без действительных коренй (ошибка)
```
$ node index.js 9 -6 2
Для введеных аргументов нет действительных корней... Зато есть комплексно-сопряженные!
 x1 = 0.3333333333333333 + 0.3333333333333333i, x2 = 0.3333333333333333 + 0.3333333333333333i
Увы, но согласно ТЗ, это все равно ошибка.
```
